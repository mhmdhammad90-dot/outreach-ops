# عمليات Outreach

نظام خفيف لمتابعة زيارات فرق الصحة والتغذية من العيادات إلى المخيمات ومراكز الإيواء.

## المحتوى
- نظرة عامة، سجل العمليات، الخطة الأسبوعية، العيادات، النقاط والمخيمات، الكوادر، التقارير.
- بطاقة زيارة لكل عملية بصيغة PDF وJPG، مع تحديد الـFocal Point ورقمه.
- ألوان Project HOPE المعتمدة.

## البيانات المشتركة (Supabase)
- البيانات محفوظة في مشروع Supabase باسم `outreach-ops`، ويراها كل من يفتح الرابط ويتحدّث العرض لحظياً.
- العرض متاح للجميع. الإضافة والتعديل لأعضاء الفريق فقط، ويدخلون برابط يصل إلى بريدهم بدون كلمة مرور.
- المشرف يضيف أعضاء الفريق ويحدد صلاحياتهم من «لوحة المشرف ← الفريق والصلاحيات»، ويدير العيادات والنقاط والعناوين، ويحذف السجلات.
- إعداد قاعدة البيانات موجود في `supabase_setup.sql`.

## التشغيل
الموقع ملف `index.html` واحد بلا أي بناء. فعّل GitHub Pages من Settings ← Pages ← Deploy from a branch ← `main` / root.
